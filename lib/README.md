# جمعية عشاق المستقبل

نظام إدارة جمعية عشاق المستقبل - تطبيق Flutter متكامل

## المميزات

- **المدير العام**: إدارة كاملة للمستخدمين والوكلاء والمساهمين
- **مدير الصندوق**: صلاحيات محدودة مع حد أدنى للسداد 500 ريال
- **الوكيل**: إدارة المساهمين التابعين له
- **المساهم**: متابعة رصيده وكشف حسابه

## الأدوار

| الدور | الصلاحيات |
|-------|-----------|
| 👑 المدير العام | صلاحية كاملة |
| 💰 مدير الصندوق | صرف مع حد أدنى 500 ريال |
| 🤝 الوكيل | إدارة مساهميه |
| 👤 المساهم | متابعة حسابه |

## المتطلبات التقنية

- Flutter 3.22.0+
- Firebase (اختياري)
- Android 5.0+
